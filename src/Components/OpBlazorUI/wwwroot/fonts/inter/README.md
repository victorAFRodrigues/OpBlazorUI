# Inter Variable

Tipografia padrão do OpBlazorUI.

- Versão: 4.1
- Origem: https://rsms.me/inter/
- Arquivo: `InterVariable.woff2`
- Licença: SIL Open Font License 1.1 (`OFL.txt`)

O `inter.css` define a família `"Inter var"` usada por `--op-font-family` em
`optimus-base.css`. Para usar outra fonte, sobrescreva a variável:

```css
:root {
    --op-font-family: system-ui, -apple-system, "Segoe UI", sans-serif;
}
```
